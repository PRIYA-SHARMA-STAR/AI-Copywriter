# 🤖 AI Copywriter

An AI-powered copywriting application built with **Python, Streamlit, and Groq API** that generates engaging marketing content based on the product, platform, tone, creativity, and focus.

## 🚀 Live Demo

👉 [Try AI Copywriter Live]

https://ai-copywriter-w275lgxscgcq3tuunxqmss.streamlit.app/
## ✨ Features

- 📦 Product-based marketing copy generation
- 📱 LinkedIn, Instagram & Email content
- 🎭 Multiple tone options
- 🔥 Adjustable creativity
- 🎯 Adjustable focus
- ⚡ Fast AI-powered generation
- 📥 Download generated copy as TXT

## 🛠️ Built With

- Python
- Streamlit
- Groq API
- Llama 3.3 70B
- python-dotenv
